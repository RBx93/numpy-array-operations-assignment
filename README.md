# numpy-array-operations-assignment
NumPy Array Operations Assignment

This assignment introduces fundamental NumPy array operations using a simple workflow built around a 1D array of random values drawn from a uniform distribution. The goal is to practice array creation, reshaping, mathematical operations, and basic linear algebra.

Tasks

Create a 1D NumPy array

Shape: 1 × 5

Values drawn from a uniform distribution

Compute descriptive statistics

Mean

Standard deviation

Reshape the array

Convert to a 2D array with shape 5 × 1

Apply element-wise transformation

Add 5 to each element

Print the updated array

Compute the dot product

Dot product of the reshaped array with itself

Print the resulting value

Each step requires printing the intermediate results to verify correctness and reinforce understanding of NumPy operations.

How to Run
pip install numpy
python main.py

Or open the notebook version in Google Colab.
